# Windows Useful Utilities

A collection of simple Windows utilities I made mainly for **fun, learning, and convenience**.

I got tired of typing the same commands one by one, so I decided to put some of them together into my own little Windows utility. It's also pretty satisfying to see my own code actually running and doing useful stuff.

This isn't meant to replace tools like **Chris Titus Tech's Windows Utility** or other Windows utility tools. Those are much more complete. Mine is just a collection of **simple personal utilities** that I made for myself while learning.
